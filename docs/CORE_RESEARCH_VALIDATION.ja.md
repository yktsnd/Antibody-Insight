# 実在抗体を用いる中核研究体験の検証

[English](CORE_RESEARCH_VALIDATION.md) · [開発順序](../DEVELOPMENT_PLAN.md) · [現在の不足](../KNOWN_LIMITATIONS.md)

## 2026-11-14の実行優先順位

最初の課題は「実在する抗体候補のうち、どちらを残し、次に何を測るか」とする。
P01/J01/AC-J01の候補選定、P02/J02/AC-J02の残基と設計理由、P04/J04/AC-J04の物性根拠、P07/J07/AC-J07の判断保存、P08/J08/AC-J08の復元を一つの案件で検証する。
この案件の結果は、各業務の個別の受入条件に照らして判定する。

1. **一案件の入力を確保する。**
   通常の配列ファイル、鎖と残基を照合できる構造、出典と版のある番号付け、選定を左右する測定指標をそろえる。
   測定ごとに元の分子、コンストラクト、試料、ロット、値、単位、条件、時差付き取得日時の対応を確認する。
   D44.1/D1.3は配列と構造の比較に使える。
   選定に必要な実測が両候補で確認できる案件を採用する。
   追加調査の上限は2人日相当とする。
   上限に達しても揃わなければ、共有可能な実案件の入手と、不完全な原記録を保留できる最小案を、具体例とともに判断に回す。
   後者は来歴と比較可否の規則を明示し、承認と独立レビューを経て着手する。

2. **同じ案件を使って、判断までの操作を改善する。**
   現行版で最初に止まる箇所を再現し、クリック、スクロール距離、画面往復、転記、所要時間を記録する。
   Wでは選んだ残基から構造上の位置と設計可否を確認し、Rでは開いた原観測を候補とともに判断フォームへ引き継いで、研究者が採用する根拠を確認できるようにする。
   修正範囲はその案件で再現した障害に絞る。
   1440×1000で主要な比較と次の操作を確認し、同じ課題を現行版と修正版で測る。
   入力が欠けた場合は、実際に到達した工程までを基準測定に使う。

3. **保存された判断を第三者が再構成できることを確認する。**
   研究者に課題と入力ファイルを渡し、操作の誘導なしで実施してもらう。
   人が照合した番号対応を使って変異案を検討し、対象残基と親子関係を保存する。
   実測と構造を参照して選定理由、未確認事項、次の実験を判断記録に残す。
   別の研究者が保存プロジェクトから対象、根拠、条件、選定理由と次の実験を説明できれば、この案件の研究者評価を合格とする。
   再起動と空のデータベースへの再取込で、判断版と参照先が一致することも確認する。
   科学的照合と操作評価の担当者の確保は、入力の調査と並行して進める。

実データの一案件がこの条件を満たした時点で、残りの役割に展開する。
J03の予測、J05の構成、J06の発現に関する追加調査や機能追加は、選んだ案件に必要な場合か、次の展開段階で扱う。
重大な同一性、来歴、セキュリティ、既存経路の回帰の欠陥は、見つけた時点で優先する。
リリースでは実データ8経路、18種類の科学的照合、実研究者による8役割の評価、指定試験の全件合格、未解決のP0/P1が0件、六つのゲートの合格を確認する。

現在の第一候補はD44.1とD44.1desである。
2019年の論文にFab同士のSPR比較があり、両候補の実験構造が公開されている。
1440 × 1000の現行版では、指定残基の構造上の位置と判断画面の条件選択欄まで確認した。
SPRの測定と試料ロットの対応、時差付き取得記録、番号対応の人手照合が残る。[原資料の確認と現行版の基準測定](../TEST_EVIDENCE/M14-d44-selection-source-and-baseline.md)

## 実案件の検証手順

確認する問いは、候補間の違いがどの分子・残基・試料・測定条件に由来するかを説明し、根拠のある変異案、次の実験、選定理由を別の研究者に渡せるか、である。

合成例は操作を確認するためのものとし、通常のファイルから実資料を登録する試験を別に行う。公開実験構造1MLCにはFab D44.1の配列と座標が含まれるが、実際の試料の同一性、測定値、人が照合したIMGT番号対応を代用しない。不足する資料を架空の記録で埋めない。

1. 通常のFASTAを開き、レコードごとに候補ID、鎖ID、役割を明示する。全鎖の配列と宣言した分子形式を確認して保存する。従来のFASTA取込では別候補になることも確認する。ファイル名・ハッシュ・元のレコードと行番号を残す。
2. 実際のPDB/mmCIFを対象候補に登録し、原資料に基づく鎖・残基対応を用いる。同一残基の連続、欠損座標、挿入コード、代替配座を独立に照合する。ポリマー内の順序が一致しても、アラインメントの正しさが保証されるわけではない。
3. 原資料があるコンストラクトと試料を来歴付きで登録する。実測CSVには実際の測定日時、単位、条件、出典を記録し、試料を明示的に対応付ける。資料がなければ、この段階は未達とする。
4. 試料と条件を区別して元の観測値を比較する。欠測と比較可能性の限界を示し、違いについて何が言えるかを説明してから、実験や変異案を選ぶ。
5. 実際の配列に対し、出典・版が明らかで、人が照合した番号対応を用意する。W/Dで対象位置と参照を確認し、理由と子候補の系譜を保存する。親の実測・番号対応・構造を子の観測として継承しない。
6. 提案段階の仮説と次の対照実験、選定理由と正確な根拠を保存する。別の担当者が「なぜ残したか」「次に何を測るか」を再構成できるか確認する。再起動と空の保存領域への再取込でも同じ対象と根拠を保持する。

各段階で、入力資料、保存ID、操作記録、科学的な問いに答えられたか、外部ツールへの戻り、IDの再入力、根拠の探し直し、文脈の中断を記録する。研究者の従来の方法と所要時間を比較し、クリックが成功したことだけで改善を推定しない。実装、独立した工学的検証、人手による科学的照合、説明を受けない研究者の利用評価を分ける。

公開1MLCでは、通常のFASTAで重鎖・軽鎖を登録し、元のmmCIFの鎖を指定して432残基の対応を作成できた。配列と3Dを相互に選択し、元の座標を参照する実験案の保存と再取込まで独立検証した。両鎖に対するANARCIの実出力も取り込める。番号付き設計に必要な人の照合記録と、実測に基づく選定に必要な元の試料・測定記録は未確認である。[座標の独立検証](../TEST_EVIDENCE/M7-deposited-independent-review.md)・[公開資料](../fixtures/public/README.md)

[独立した実現可能性レビュー](../TEST_EVIDENCE/M6-real-core-independent-gap-review.md)では、具体的な境界も確認した。[D44.1の論文](https://pmc.ncbi.nlm.nih.gov/articles/PMC2803018/)は酵母表面提示の単鎖抗体を測定しており、その実測を1MLCのFab試料へ付け替えることはできない。変異体と野生型の比を、変異体の独立した絶対測定値として保存しない。現行の必須項目であるロットとイベント日時が原資料にない場合も、測定CSVの経路は完了できない。出版日・取込日時、架空のロット、PDB著者番号とIMGT番号の読み替え、実在しない人の照合記録で補わない。まず、既存の科学ツールの出力と実際の来歴を利用し、対応表の準備の負担を減らす。不明な来歴をより詳しく表す設計が必要なら、別途レビューと承認を経てから変更する。

別の公開実測候補として、MBDBのB09ナノボディの登録情報とMST原ファイルを確認した。測定日時は原ファイルにExcelの日時値として保存されている。確認したセルにはタイムゾーンがない。登録日と公開日はデータベース側の日付である。現行の測定取込に使うには、配列・コンストラクトとの関係、元の試料ロット、タイムゾーンを確認できる測定記録が必要となる。[MBDBの登録情報と原ファイル](https://mbdb-data.org/mst/5s81t-w6s49)

NIST FabのHDX-MS研究では、出発材料がCandidate RM 8670のロット5F1bであり、参照構造が5K8Aであることを確認した。
公開ワークブックには相対日、ラン番号、重水素交換時間が記録されている。
実測値の取込には、対象行の取得日時、各測定に使った試料との対応、値の単位を確認できる資料が必要となる。
5K8Aの画面検証では、軽鎖の座標対応と、重鎖N末端の修飾により全鎖の対応付けが保留されることを確認した。[公開資料の確認記録（英語）](../TEST_EVIDENCE/M8-nist-fab-source-preflight.md)

NISTmAbのMAM共同研究では、参照消化試料の元ロットと、二つの測定ランの時差付き取得日時を原資料で確認した。
公開された集計値を実測として取り込むには、個別ランの値と条件を示す資料が必要である。
別の5年安定性報告には、未消化IgGのロット・ラック別のSECおよびCE-SDS測定値がある。公開表には個別取得の時差付き日時がない。[MAMの確認記録（英語）](../TEST_EVIDENCE/M12-nist-mam-source-preflight.md)・[NIST SP 260-237の表A2・A3](https://doi.org/10.6028/NIST.SP.260-237)
