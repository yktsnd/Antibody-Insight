# ADR-0007 Source-linked concerns and structural observations

- Status: ACCEPTED within independently verified F12/F13 engineering scope. Current full J01–J04 replay PASS; source-commit acceptance registration follows. Full M3 and release remain incomplete.
- Trace: F12 P03/P04, J03/J04, AC-J03/AC-J04 (source position → evidence → hypothesis); F13 P03/P04, J03/J04, AC-J03/AC-J04 (usable structural inspection).
- User need: P03 must retain exactly what was observed in a particular model before proposing a variant hypothesis. P04 must reach a source-reported concern from the original property result, inspect its actual residue/structure, and save a child design and next test without conflating measured and computed data.
- Priority rationale: required missing J03/J04 workflow links, with identity/provenance/security/regression gates mandatory. Rubric assessment: F12 directness5×6 + scenario breadth3×5 + trust5×4 + barrier removal5×3 + low effort4×2 =88; F13 directness5×6 + breadth3×5 + trust4×4 + barrier removal5×3 + low effort4×2 =84. These are engineering prioritization estimates, not scientific utility scores. Native viewer reuse keeps the implementation bounded.
- Action/result: follow a reported residue from W/R; inspect the original source/mapping, focus the selected residue in the local viewer and choose a familiar representation; review source model/residue context with the proposed hypothesis. E's existing exact-condition ordering and D's verified substitutions are reused.
- Inputs/outputs: optional explicit Evidence residue references and optional Hypothesis source-residue context; existing immutable sequences/maps/structures → connected inspection and preserved proposed reasoning. No prediction, risk score, bond validation, inferred numbering or threshold is produced.
- Evidence anchors: optional `residue_refs` list of actual chain/raw-index pairs, resolved only on the Evidence's own Material→Construct→Molecule / direct subject path. These are explicitly source-reported position associations; they do not localize a whole-Material measurement to a residue or establish a liability. UI uses “Source-reported position”, retaining the actual subject, kind, method and conditions. Optional `description` retains a source-supplied qualitative note, instead of hiding a concern inside assay conditions or inventing a scalar. Type/units/conditions/source stay unchanged. An unrelated chain, out-of-range index or duplicate anchor rejects atomically. No matching by equal sequence or parentage, no classification from note text. Source-only antigen coordinates never acquire antibody sequence or Material attribution.
- Hypothesis structural residue: optional source key + actual alternate-location identifier within an existing structural reference. It must exist in the named source/model; model/mapping checks remain strict. Unknown source fields stay null. Source-only residues may be retained without claiming sequence correspondence. Existing hypotheses remain byte-for-byte valid; no migration.
- UI state: persist opaque residue UID/alt and existing view IDs only. Resolve full source keys from local immutable source data in memory when preparing the reviewed hypothesis. Do not put amino-acid names, coordinates, property values or draft scientific text into localStorage.
- Reuse: Mol* component/selection/focus patterns and 3Dmol's documented atom/ball-and-stick primitives; retain the pinned local 3Dmol/Gemmi adapter and source identities. Jalview sequence-feature/source associations inform reported-position links. Sources and comparison are recorded in SCIENTIFIC_UX.md before the interface change. No new dependency or remote service.
- Representations: source atom positions remain exact. Native distance-based single bonds, if requested, are explicitly a rendering aid, not validated chemical connectivity; mutually exclusive/unknown alternate states must not acquire spurious bonds. Offer original atoms, ball-and-stick and C-alpha atom overview (standard amino-acid residues only), with the selected residue shown in atomic detail. No invented secondary structure, surface confidence or cartoon annotation.
- Focus: use the renderer's existing zoom-to-selection on the exact selected source atoms, not nearest coordinates or an unmapped neighbouring residue. Keep camera/mode/selection across navigation and restart. Source-only selection is explicitly distinct from a mapped sequence position.
- Real-scale validation: pin an unmodified public PDB coordinate file, source URL/revision/SHA256 and licensing. Use deposited sequence/chain/entity/label fields for explicit test mappings. This verifies actual antibody-scale rendering and source preservation, not prediction accuracy or the human scientific-golden gate. Runtime remains offline; tests use the checked-in input, never a download.
- Main tests: full named J03 E→W chain/model correspondence + physical reciprocal selection/camera→R confidence/source/limits→D saved variant hypothesis→restart; full named J04 property ordering→source concern/structure→distinct measured/computed inspection→numbered child→R hypothesis/next experiment→restart. Save/export/reimport exact records; no child measured copying.
- Required negatives: J03 unmappable residues never select a different sequence position; absent confidence is not synthesized. J04 mismatched units do not join a numeric context; unknown conditions are not pooled. Extra edges: wrong subject/model/conformer references, stale source requests, renderer mode/focus identity, real-sized structure with missing/alternate atoms, old bundle compatibility.
- Non-goals: automatic liability/humanization prediction, structural optimization/superposition, interactive assembly/J05, M4 comparisons/decisions, full J08 adapters and final release validation.
- Rollback/gates: additive optional fields and view controls only, append-only existing persistence. No original source record is rewritten. Design/implementation independent PASS and fresh retained journeys are required before registration; other journeys remain pending.
