# ADR-0006 Numbered substitutions and retained research hypotheses

- Status: design PASS; implementation and full journeys await independent replay.
- Date: 2026-11-03. Owner: implementation agent.
- Trace: F10 (P02/P04, J02/J04, AC-J02/AC-J04), F11 (P02/P03/P04/P06, J02/J03/J04/J06 and their ACs).
- Original need: let the researcher turn an observed difference or concern into a precise child design and a testable, source-linked hypothesis. This closes the main missing M3 reasoning path rather than adding an analysis tool.
- User action: inspect parent/reference numbering in W/D; choose exact source-bearing coordinates; preview substitutions and parent/child differences in D; save a new child and lineage; record the reason, original evidence, uncertainty and next experiment in R. D can save a proposed variant hypothesis without asserting that a child or measurement exists.
- Inputs/outputs: existing Molecule/ResidueMap/Evidence/Structure → new Molecule + substitution Lineage, and a distinct proposed Hypothesis. Preview writes nothing; existing atomic import saves reviewed new records. Parents and source records remain immutable.
- Options: A, reuse validated imported coordinates and explicit human choices; B, add a new numbering/prediction engine or infer replacements from a humanness score. Choose A. Neither numbering, human species, improved function nor a humanness score is inferred.
- Position identity: parent molecule + chain + imported map/domain + scheme + integer number + exact insertion code; record resolved raw index/from/to amino acids. Multiple maps never use first/latest fallback. Failed/unavailable/unverified maps and absent coordinates cannot authorize a mutation. An eligible partial domain may authorize its actually observed positions; full CDR/reference completeness remains a separate state.
- Reference: optional explicit imported reference map of the same scheme/domain definition and chain type. Join exact coordinates and retain both sources. Gaps stay unavailable. A human reference is a researcher-supplied reference, not a sequence-derived classification. No automatic grafting or identity score.
- Child: preserve all unmodified chains/format and component topology. No parent Construct, Material, Evidence, Structure, structure correspondence or verified numbering is copied to the child. Parent numbering locates the design; it does not attest to the child's numbering or function.
- Component declarations: update each touched component's sequence in place. A changed segment cannot retain an exact BindingUnit interval it no longer matches; its child component origin is explicitly null. The preview shows this change and lineage retains the exact parent composition and substitution provenance. Unchanged component origins remain exact. A chain substitution affects all declared copies of that chain, stated before save. No copy-specific physical claim is made.
- Hypothesis: distinct immutable `hyp_` record, status proposed only; text, next experiment/question, recorded limitations, target molecule IDs, original Evidence IDs, related lineage and explicit residue/structure contexts. Local entry/source version and creation time are recorded; no named author or validation is fabricated. Parent evidence stays visibly parent evidence.
- Compatibility: additive awx/1 entity/lineage support, no rewriting/migration. Older readers reject unsupported types explicitly. Preview+save and import both revalidate actual references and full differences.
- Confidentiality: existing loopback/session/CSRF controls, no network service. Unsubmitted mutation/text drafts stay in memory; localStorage retains only accepted UI IDs/view context. Saved records belong in SQLite/export.
- Test main: full J02 parent VH/VL + declared human reference → exact IMGT/FR/CDR observation → insertion-aware changes → parent/child differences → R hypothesis/reason/evidence → restart and roundtrip; no child measured records.
- Prescribed J02 negatives: numbering unavailable/failed never succeeds; inserted coordinate cannot alias its integer neighbour or another chain, missing correspondence remains explicit. Additional negatives: fabricated/stale map identity, duplicate/no-op edits, changed-origin mismatch, partial save, unrelated hypothesis evidence and wrong structure model.
- F11 J03/J04: retain confidence/source/limits and explicit structural context in a proposed variant hypothesis; combine F09 ordering, F08 observation and F10 child creation for the complete J04 action. Full J03/J04 acceptance requires their own named browser paths, not an inferred count from J02.
- Non-goals: model execution, automatic humanization, biological success/affinity claims, indels, interactive assembly (next M3 action), construct/measurement comparison and finalized decisions (M4).
- Reviewer: `/root/j01_replay_review`, TEST_EVIDENCE/M3-design-independent-review.md. All new saves are append-only; isolate test databases and leave existing records untouched. Escalate any unresolved change to scientific meaning or product scope.
